## Лабораторная работа №14
### Разрешение конфликтов при слиянии

``` git
git rebase --continue
git merhe hello
git merge master
git add .
```
### Результат.
![Меню](https://github.com/thesonyakap/Software_engineering/blob/Тема_1/pic/Снимок%20экрана%202025-09-14%20в%2010.20.37.png)

## Выводы
В случае, если возникли конфликты при слиянии (merge) необходимо:
начать команду слияния, затем открыть файлы с конфликтами с помощью '<<<<<<<HEAD'и '>>>>>>>имя_ветки', разрешить конфликты, оставить только код, который должен остаться, добавить измененные файлы. И потом можно продолжить операцию слияния и завершить её

## Общие выводы по теме
Гит - популярный рабочий инструмент контроля версий. С помощью него можно:
- Управлять версиями кода, можно сохранять историю изменений, откатывать код в случае неполадок
- Совместно работать. Над одним проектом могут одновременно работать несколько разрабочтиков
- Создавать ветки и осуществлять слияние
- Просматривать историю изменений
- Восстанавливать данные из прошлых коммитов
- Работать в своём локальном репозитории
- Эффективно управлять и разрешать конфликты

Ключевая ценность Git заключается в простоте настройки и эффективности при разработке.
