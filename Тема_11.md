## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобными применением

```
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self
    
    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == "__main__":
    counter = CountDown(5)
    for i in counter:
        print(i)
```

![Меню](https://github.com/thesonyakap/Software_engineering/blob/Тема_11/pic_lab11/Снимок%20экрана%202025-11-21%20в%2022.50.29.png)

## Выводы
Этот класс создаёт итератор, который считает вниз от заданного числа до 0.
Мы сохраняем число start + 1, потому что первым шагом в __next__ будет уменьшение счётчика.
Каждый вызов: уменьшает значение на 1, возвращает его, когда становится меньше 0 останавливает цикл.

## Лабораторная работа №5
### Такой же счётчик, как и в первом задании, только это генератор и использует yield

```
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```

## Выводы
Код реализует генератор обратного отсчёта: функция countdown() по очереди выдаёт числа от переданного значения до нуля, и цикл for последовательно выводит каждое из них.

## Самостоятельная работа №1
### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b


n = 200
fibs = list(fib(n))
print(f"200-е число Фибоначчи: {fibs[-1]}")
```

def fib(n):

## Общие выводы по теме
Итераторы и генераторы в Python — это мощные инструменты для последовательного перебора данных и ленивых вычислений. С их помощью можно:
- Создавать объекты, которые можно перебирать в циклах for, используя методы __iter__() и __next__().
- Генерировать последовательности «на лету» с помощью yield, экономя память при работе с большими данными.
- Организовывать обратные отсчёты, последовательности Фибоначчи и другие вычисления без необходимости хранить все элементы сразу.
- Повторно использовать списки, а генераторы позволяют обходить данные только один раз, что делает их эффективными для потоков информации.

Ключевая ценность итераторов и генераторов заключается в их эффективности, простоте перебора и гибкости, позволяя обрабатывать большие объёмы данных без значительной нагрузки на память.
