## Самостоятельная работа №5
### Самостоятельно реализуйте полиморфизм. Он должен отличаться, от того, что указан в теоретическом материале (методичке) и лабораторных заданиях. Результатом выполнения задания будет листинг кода и получившийся вывод консоли.

```
class Drink:
    def make(self):
        print("Готовится напиток...")

class Coffee(Drink):
    def make(self):
        print("Готовится кофе")

class Tea(Drink):
    def make(self):
        print("Заваривается чай")

def prepare(drink):
    drink.make()

prepare(Coffee())
prepare(Tea())

```

### Результат.
![Меню](https://github.com/thesonyakap/Software_engineering/blob/Тема_8/pic_lab8/Снимок%20экрана%202025-11-01%20в%2023.01.13.png)

## Выводы
Код демонстрирует наследование и полиморфизм в Python.
Класс Drink базовый, с методом make(), который выводит сообщение о приготовлении напитка.
Классы Coffee и Tea наследуются от Drink и переопределяют метод make(), чтобы выполнять собственные действия.
Функция prepare() принимает любой объект, у которого есть метод make(), и вызывает его.
В результате при вызове prepare(Coffee()) и prepare(Tea()) программа выводит разные сообщения:
Готовится кофе  
Заваривается чай
